# Sample Episode Brief

## Basic Info

- Episode number: 01
- Working title: 为什么逻辑回归能做分类？
- Topic scope: logistic regression 的分类本质、sigmoid、对数几率、决策边界
- Target audience: 准备算法 / 机器学习岗位面试的本科生与研究生
- Difficulty: Basic

## Goal

这一期最想解决的一个核心问题是：为什么一个名字里带“回归”的模型，却常常被用来做分类。

## Why This Topic

这是非常高频的机器学习面试小切口，既有传播性，也容易暴露候选人是否只会背结论。

## Expected Reader Gain

1. 解释 logistic regression 的输出含义
2. 说清 sigmoid、log-odds 和分类决策之间的关系
3. 用较完整的面试语言回答这道题

## Candidate Interview Questions

- Q1: 为什么 logistic regression 明明叫 regression，却能做 classification？
