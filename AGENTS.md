# AGENTS.md

## Mission

Build a repeatable content pipeline for a Xiaohongshu series on real machine learning interview questions.

The output of each episode must:

- target machine learning / AI interview preparation
- fit into 5–6 pages
- use the user's existing LaTeX template
- distinguish clearly between verified public interview questions and classic variants
- ground explanations in publicly taught concepts from top US university course materials
- remain concise, structured, and social-media readable

## Always

- keep the main topic narrow: one episode, one core concept cluster
- prioritize interview usefulness over encyclopedic coverage
- keep page density balanced
- preserve the user's LaTeX structure and style tokens
- mark source confidence explicitly
- use cautious wording when source provenance is incomplete
- keep math in valid LaTeX
- write Chinese-first, with English terms on first mention when helpful

## Never

- never fabricate a company-specific “real interview question”
- never invent a university slide deck, professor, or lecture number
- never dump raw textbook prose into pages
- never exceed the target scope with 3–4 unrelated subtopics in one episode
- never silently alter the user's visual template architecture
- never state uncertain sourcing as confirmed fact

## Required Output Structure Per Episode

1. episode title
2. core interview question(s)
3. page-by-page plan
4. LaTeX-ready body content
5. source confidence notes
6. QA summary

## Source Confidence Labels

Use one of the following labels whenever question provenance is mentioned:

- Verified public interview report
- Repeated in public interview writeups
- Classic interview variant
- Course-derived high-frequency concept question
- Source not fully verifiable

## Standard Page Pattern

- Page 1: cover and hook
- Page 2: interview question framing
- Page 3: concept breakdown
- Page 4: answer template
- Page 5: pitfalls / follow-up / comparison
- Page 6: recap and next-episode bridge if needed

## Content Acceptance Gate

An episode is acceptable only if all are true:

- the topic is narrow and interview-relevant
- question source wording is cautious and accurate
- the explanation is not merely definitional; it includes intuition and interview framing
- the page count target is respected
- the content can be inserted into the existing LaTeX template with minimal edits

## Compact Handoff Instructions

When context must be compressed, preserve:

- current episode topic
- selected interview question(s)
- source confidence decisions
- page plan
- template constraints
- unresolved verification risks
