# Episode Production Workflow

单期生产建议严格按这个顺序执行。第一步先做选题收敛，只选一个足够小的切口，例如“为什么逻辑回归能做分类”或者“BatchNorm 真正解决了什么问题”，不要一开始把一整块模型体系都塞进一期。第二步做题目收集与来源分级，把题目区分为可验证公开面经、公开面经高频变体、经典面试题型三类。第三步做知识点映射，把这一期需要讲的概念对齐到公开课程里常见的知识框架，比如定义、直觉、公式、应用场景、局限性。第四步填写 `episode-brief.md` 和 `source-log.md`。第五步先做 `page-plan.md`，按 5–6 页分配信息密度。第六步再生成 LaTeX 正文。第七步用 review gate 检查是否存在范围膨胀、题源措辞过满、分页失衡、模板侵入式改动等问题。第八步输出最终发布稿。

这个顺序的核心不是形式感，而是防止两个常见问题：一是生成时越写越散，最后像讲义而不是小红书；二是为了“显得硬核”把来源说得比事实更确定。只要把选题、来源、分页、正文、验收拆开，Codex 的稳定性会明显更高。
